Notas de Requisitos para Importación Excel/CSV

Formato de Archivo
  • Archivos soportados: .xlsx, .xls, .csv
  • Tamaño máximo: 10 MB
  • Codificación recomendada: UTF-8
Estructura de Columnas
{% if tipo == 'equipos' %}

  • Primera fila debe ser encabezados
  • Columnas requeridas: Unidad Académica, Carrera, Asignatura, Nombre del Equipo
  • Estados válidos: Bueno, Regular, Malo
{% elif tipo == 'insumos' %}
  • Debe contener las 19 columnas oficiales
  • Primera fila debe ser encabezados
  • Columnas requeridas: Unidad Académica, Laboratorio, Nombre del Elemento
  • Categorías válidas: Reactivos, Materiales, Herramientas

  • No debe tener celdas completamente vacías
  • Las Unidades Académicas deben existir en el sistema
  • Las Carreras deben estar asociadas a la Unidad correcta
  • Los Laboratorios deben estar registrados previamente
